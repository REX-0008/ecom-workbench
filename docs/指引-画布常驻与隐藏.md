# 指引 · 画布常驻与隐藏

> 从 `AGENTS.md` 移出来（2026-10-26）：只在动画布挂载、tab 切换、`.pane` 那一层时用。
> 触发条件：想「优化」画布的挂载方式、改 tab 切换、调整 `.pane` 的隐藏方式。

**画布必须常驻挂载**，不能按 tab 条件渲染 —— `EcomWorkbench.tsx` 用 `.pane`
把它绝对定位铺满，非当前 tab 时藏起来。

原因：节点与连线是画布组件内的 `useState`，卸载即丢；而撤销栈是模块级 store、
不随卸载销毁 → 切回来「屏幕」与「历史」对不上。

**怎么藏是有讲究的，四条都踩过**（详见 `EcomWorkbench.module.css` 的 `.pane` 注释）：

1. **必须用 `opacity:0`** —— 它作用于**整棵子树**，后代覆盖不掉
2. **不能用 `visibility:hidden`** —— 它是能被后代覆盖的继承属性，而 React Flow
   给每个节点写了**内联** `visibility:visible`，优先级最高，会把祖先的隐藏顶掉
3. **`pointer-events` 有同一个陷阱**：节点带内联 `pointer-events:all`，
   隐藏时要 `!important` 压住整棵子树，否则会吃掉本该落在列表页上的点击
4. **不能用 `display:none`** —— 尺寸变 0，React Flow 拒绝渲染视口（「错误 004」）；
   **也不能留在正常流里** —— 即使不可见，`flex:1` 仍会占高度、把别的 tab 挤扁

另外要把 `active` 传给画布：隐藏时它必须**停掉自己的全局键盘监听**，
否则用户在列表页按 Ctrl+Z / Delete 会默默改到看不见的画布上。
