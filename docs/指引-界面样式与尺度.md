# 指引 · 界面样式与尺度

> 从 `AGENTS.md` 移出来（2026-10-26）：只在动界面样式时用，不该常驻每次请求。
> 触发条件：改 `src/client/workbench/` 下的样式、加控件、调层级、处理布局溢出。
> 设计取向与色板全文在 `../设计计划.md`；本文是**落地规则**。

## 一、主题层跟随 dsh，画布内保留自己的

这划定所有颜色决策：

- 底、面、文字、边框 → `--dsw-alias-*`（dsh 语义层，亮暗两套值，引用即跟随主题）
- 节点的状态色、类型色、端口色 → 自定，多种颜色承担「一眼看出区别」的职能

**颜色纪律**：

- **丰富颜色只允许出现在画布内**，且只在**节点与端口**上 —— 那里每个颜色都有明确职能
  （9 个类型色回答「是什么」，7 个状态色回答「怎么样了」）
- **外壳（侧栏、顶部、列表、tab）不出现大面积颜色**。强调色只做两件事：
  标记**选中态**、标记**主操作**；语义色只出现在**徽标**这类小面积处
- **主题界面求安静**：颜色是点缀，不是主体

**字号分两类**：正文类读 `--dsh-content-font-size` 跟随用户设置；
装饰性密集小字用 dsh 固定档。**字体栈引用 `--dsw-font-family` / `--ds-font-family-code`** ——
dsh 的等宽栈不带裸 `monospace` 尾巴，Windows 中文会掉宋体。

## 二、Tailwind v4 与 CSS Modules 并存

入口 `src/client/styles/tailwind.css`，接入方式照 `my-dsh-plugins/context-panel-write`。四条硬约束：

1. `@tailwind utilities;` 在文件最后一行，其后无内容
2. 注释里出现 `*/` 会提前结束注释，残渣进产物导致构建报 PARSE_ERROR
3. 定义新工具类前先确认对应主题变量存在 —— Tailwind 只发射有变量的类（`font-mono` 曾因此整体静默失效）
4. **不引 preflight，所以盒子模型默认不是 border-box** —— 入口已用
   `:where([data-ewb-column],[data-ewb-drawer]) *` 补回（只作用于我们的容器）

**照 Tailwind 的假设写 `w-full` + `px-*` 就是对的，别再手动扣内边距；
见「边距不对 / 贴边」，先查盒模型，再查间距**（第 4 条的代价就是卡片右内边距消失过，
当时两轮都误判成间距问题）。

## 三、三套尺度取值

取值在 `src/client/styles/tailwind.css` 的 `@theme` 里，
**新增样式从这三套里取值，不写任意值**（`text-[13.5px]`、`gap-[11px]` 违规）。

**层级三层**：T1 当前正在做的事 · T2 支撑信息 · T3 只需存在。
判据是「说不出这一屏最重要的那个元素，就等于没有层级」。

| 约束 | 规则 |
| --- | --- |
| 字重 | **只用两种**：`font-semibold`(T1) 与不写(400)。禁用 `font-medium` / `font-bold` / `font-light` |
| 文字颜色 | **最多三种**：`label-primary` / `-secondary` / `-tertiary`，按层分配后不变 |
| 字号 | 6 档语义 token：`text-ewb-title`(20) / `-heading`(16) / `-body`(14) / `-meta`(13) / `-label`(12) / `-caption`(11) |
| 圆角 | 3 级：`rounded-ctl`(6px 控件) / `-card`(10px 容器) / `-full`(胶囊) |
| 间距 | 取 Tailwind 阶，**成比例**而非「4 的倍数」 |
| 深度 | 2 级：`--shadow-2` 浮起（下拉/弹出层） / `--shadow-3` 最高（对话框/抽屉） |

**字号不单独扛层级**：先动字重与颜色，最后才动字号。
**图标与相邻文字不同色**：用颜色差，不用透明度差。
**入场动效只留一处**（`PageHeader`）；逐块淡入是 AI 生成的通病。

## 四、深度只有一条物理规则：光从上方来

- 浮起 = 顶边亮 + 下方投影（**Y 偏移必须为正**）
- 内凹 = 顶边暗 + 底部亮边（输入框、文本域、下拉都是内凹）
- 高光**手挑实色**，不用半透明白（会抽掉底色的饱和度）

**与画布的发光区分**：画布里那批零偏移的 `0 0 Npx` 是**状态发光**
（表达「现在怎么样了」），有意保留，不归深度规则管辖。

**独特性声明**（全文见 `../设计计划.md`）：设计力气只花在节点上 ——
9 个类型色（顶部色条）+ 7 个状态色（描边与发光），两个正交通道；
外壳、列表、tab 一律用 dsh 令牌，求安静。
