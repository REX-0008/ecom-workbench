## 四、三个重要警告

### 1. Beav 的「素材下载」依赖已登录浏览器，不是 API

它**注入页面主世界劫持 fetch/XHR** 拿数据，再**带 cookie 直链下载**。
→ **我们的下载节点不能假设有浏览器**（我们是 Node 环境）。**要么改走 API，要么明确要求用户提供 cookie**。

### 2. Beav 开源版缺两个功能（源码里没有）

- **「图片去 AI 水印」** —— 源码 grep **0 命中**
- **「图片转 Live 图」** —— 源码 grep **0 命中**

**原因**：开源版源码停在 **2.5.0**，而 CHANGELOG 已写到 **2.8.13**——**这两块只在闭源的新版里**。
→ **想看实现，这个仓库给不了；只能看软件行为。**

### 3. ProductFlow 的自动布局有 bug

`WorkflowCanvas.tsx:774-927`：BFS 队列**从不递减入度、无 visited 集合**，**有环的图会死循环**（推断）。
→ **别抄**。用现成库，或自己写**带 visited 的拓扑分层**。

## 五、TradeMind 的一个重要发现（影响我们的定位）

**它没有通用工作流/DAG 引擎**——80 处 `workflow/orchestrat` 命中**全是业务编排**（如「AI 商品图批量编排」「库存同步编排」），**不是通用引擎**。

**修正表述**：不是「行业无先例」，而是「**TradeMind 里无先例**」。因为：
- **dsh 自带 `ctx.workflowEngine`**（脚本编排 subagent）
- **dsh-node-flow 插件**有完整的节点工作流实现（已装过）
- **dsh-node-flow-skill** 有完整的 schema 规范（已装）

→ **我们的「节点 + 派发器」是增量，但不孤单**——**dsh 生态里有可参照的实现**。
